Narrative Flow v2.0.0 — Windows Portable Build
================================================

The ZIP file has been split into 3 parts due to GitHub file size limits.
Reassemble before extracting:

  Windows (Command Prompt):
    copy /b NarrativeFlow-v2.0.0-win.zip.partaa + NarrativeFlow-v2.0.0-win.zip.partab + NarrativeFlow-v2.0.0-win.zip.partac NarrativeFlow-v2.0.0-win.zip

  Linux / macOS:
    cat NarrativeFlow-v2.0.0-win.zip.part* > NarrativeFlow-v2.0.0-win.zip

Then extract the ZIP and run:
    Narrative Flow.exe

No installation required — fully portable.

What's new in v2.0.0:
  - Fixed CharacterManager (was rendering blank)
  - POV (Point-of-View) node system
  - POV canvas filter per character
  - Play mode perspective selector
